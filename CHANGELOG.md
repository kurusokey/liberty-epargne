## [1.0.0] — 2026-04-30

### Ajouté
- Plan 10 000 € en 12 mois — répartition Livret A / Assurance Vie / PEA / PER.
- Saisie mensuelle versements + soldes réels + intérêts + notes.
- Graphique 12 mois vs objectif avec projection intérêts composés.
- 4 cartes enveloppe : solde, versements cumulés, intérêts gagnés, taux annuel.
- Alerte sous-objectif (versement total < 800 €).
- Export CSV (compatible Excel/Numbers).
- Realtime multi-device via Supabase.
- Auth Supabase (single-user).
- Stack : Next.js 15 + React 19 + TypeScript + Tailwind + Supabase (Auth + Postgres + Realtime + RLS) + Recharts + Vercel.
- Domaine : https://epargne.sampapaya.com.
